# `1.py` 詳細分析

## このコードが行うこと
`1.py` は、テンプレートマッチングによる部品検出の検証スクリプトです。  
一般的な相関スコアだけでなく、テンプレート黒画素の一致率を追加判定に使うことで誤検出を減らす設計になっています。

## 入力・出力
- 入力:
  - `target_path`: 検出対象画像
  - `template_folder`: 比較用テンプレートPNG群
- デバッグ出力:
  - `debug_images/target_bin.png`（対象画像の2値化結果）
- 最終出力:
  - `result.png`（検出矩形とスコア表示を重畳した画像）

## 全体アルゴリズム
1. 対象画像を2値化する
2. テンプレートを1枚ずつ2値化する（透過PNGにも対応）
3. `cv2.matchTemplate` で候補座標を抽出する
4. 候補ごとに「テンプレート黒画素が対象でも黒か」を評価する
5. 相関スコアと黒画素一致率を合成し、NMSで重複候補を統合
6. 生存候補を矩形描画して結果画像を保存

## ステップバイステップ処理
### Step 1. 設定値の定義
- `threshold`: テンプレートマッチング相関スコアの下限
- `black_match_threshold`: 黒画素一致率の下限
- `nms_threshold`: IoU閾値（重複候補を消す基準）
- `debug_folder`: デバッグ画像保存先

### Step 2. 対象画像の2値化
- `cv2.imread(..., IMREAD_COLOR)` でカラー読み込み。
- グレースケール化後、`< 128` の画素を255（白）とする2値画像 `target_bin` を作成。
- 2値結果を `debug_images/target_bin.png` に保存。

### Step 3. テンプレート列挙
- `template_folder` 配下の `.png` を列挙してループ。

### Step 4. 各テンプレートを2値化
- RGB部分をグレースケール化して2値化。
- アルファ付きPNGの場合:
  - アルファ0（透明）画素は `tpl_bin=0` にして無効化。
- `black_coords = np.where(tpl_bin > 0)` でテンプレート黒画素座標を抽出。

### Step 5. 相関マッチングで候補位置を取得
- `cv2.matchTemplate(target_bin, tpl_bin, cv2.TM_CCORR_NORMED)` を実行。
- `res >= threshold` の位置を候補として取得。

### Step 6. 候補ごとの黒画素一致率評価
- 候補左上座標 `pt` にテンプレート黒画素座標を重ね合わせる。
- 画像外座標を除外した後、対象画像上で黒画素が立っている数をカウント。
- `match_ratio = matched / len(black_coords)` を算出。
- `match_ratio < black_match_threshold` の候補は棄却。

### Step 7. 合成スコア計算
- `match_score = res[y, x]`
- `combined_score = match_score + match_ratio`
- NMS用スコアとして `combined_score` を採用。

### Step 8. Non-Max Suppression (NMS)
- 候補矩形をスコア降順で処理。
- IoUが `nms_threshold` を超える重複候補を除去。
- 採用インデックス `keep_idx` を返す。

### Step 9. 可視化と保存
- 採用矩形を赤枠で描画。
- ラベル文字列 `"[idx] match/black"` を描画（例: `0.82/0.91`）。
- 最終画像を `result.png` として保存。

## 判定ロジックの要点
- 相関だけでなく、テンプレート黒線が実際に対象黒線と一致しているかを評価。
- 相関が高くても黒一致率が低い候補を除外できるため、見た目類似による誤検出を抑制しやすい。
- NMSにより、近傍重複候補を1件に統合する。

## 実装上の注意点
- 関数化されていないため、import時に即実行されます。
- `target_path` / `template_folder` は固定パスで、環境依存です。
- `match_ratio` は `len(black_coords)` を分母にするため、テンプレートの有効画素設計が性能に直結します。
